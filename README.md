# Sahabat Sholat Ceria

Gunakan gambar yang saya upload sebagai referensi visual utama. Saya ingin membangun aplikasi mobile-first bernama “Rajin Sholat”, bukan sekadar mockup.

Buat struktur aplikasi berdasarkan seluruh screen yang terlihat pada gambar. Pertahankan gaya visual, warna pastel, rounded card, ilustrasi anak Muslim, dan nuansa Islamic kids yang sama.

Untuk tahap pertama, bangun terlebih dahulu UI dan navigasi seluruh screen agar semuanya bisa diklik dan berpindah halaman dengan benar. Jangan membuat gambar menjadi background atau screenshot yang bisa diklik. Semua elemen harus berupa UI asli.

Gunakan bahasa Indonesia dan prioritaskan tampilan smartphone.

Setelah seluruh screen dan navigasi selesai, baru kita lanjutkan implementasi database dan logic aplikasi.
